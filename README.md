# 🚀 NeuroPlan AI

> A futuristic AI-powered study planner built with HTML, CSS, and JavaScript.
NeuroPlan AI is an immersive productivity platform designed to help students organize their studies intelligently through adaptive scheduling, focus tracking, and futuristic dashboard analytics.
Built with a cyberpunk-inspired UI/UX, the platform combines interactive animations, smart study planning logic, and modern frontend design to create a premium learning experience.

---

# ✨ Features

## 🧠 Smart Study Planning

* Dynamically generates study roadmaps
* Adaptive workload distribution based on subject difficulty
* Topic-wise scheduling system

## 📊 Interactive Dashboard

* Real-time progress tracking
* Productivity analytics
* Subject completion monitoring
* Study statistics visualization

## ⏱️ Focus Timer

* Built-in Pomodoro productivity timer
* Focus session tracking
* Minimal futuristic timer UI

## 🎨 Futuristic UI/UX

* Cyberpunk-inspired interface
* Neon glow effects & animations
* Glassmorphism design
* Responsive modern layout

## ⚡ Interactive Experience

* Smooth scrolling animations
* Dynamic hover interactions
* Reveal-on-scroll effects
* Animated particles background
